# Conteúdo de apoio — Rotina BT

O formulário de rotina não referencia imagens na v1: as etapas trazem os
detalhes em texto e as tabelas de referência (torque e pares de isolamento).

Para acrescentar apoio visual a uma etapa, use a aba de administração
(Adicionar mídia) ou edite `public/forms/rotina-bt.json`, apontando para um
arquivo gravado nesta pasta — por exemplo `/media/rotina-bt/r3-10-torque.png`.
